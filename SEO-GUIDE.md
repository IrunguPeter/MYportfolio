# SEO Guide — DevStudio (devstudio.co.ke)

A practical to-do list for ranking higher in search results as a web developer. Work through this when you're ready — nothing here is applied to the site yet.

---

## Current state

Your technical SEO foundation is already good:
- ✅ Meta description, keywords, author
- ✅ Canonical URL
- ✅ Open Graph / Twitter card tags
- ✅ robots.txt (sitemap referenced)
- ✅ sitemap.xml (submitted to Google Search Console)
- ⚠️ Only real weakness: single-page site limits content and topical authority

---

## 1. Structural: move from 1 page to multiple pages (biggest impact)

You're competing against multi-page sites. One page = limited content + weaker topical authority.

Create dedicated pages, each targeting ONE primary keyword:

| Page | Primary keyword |
|------|-----------------|
| `/services/web-design.html` | portfolio / landing pages |
| `/services/ecommerce.html` | e-stores |
| `/services/web-apps.html` | full-stack web apps |
| `/portfolio.html` | case studies with real results |
| `/about.html` | who you are, your process |
| `/blog/` | how-to / information content (the real ranking engine) |

Then update `sitemap.xml` with the new URLs.

---

## 2. Start a blog (long-term ranking power)

Target "how-to" / information keywords that build trust and eventually convert readers into clients:

- "How much does a website cost in Kenya"
- "How to create a portfolio website"
- "Website design process explained"
- "Common website mistakes small businesses make"
- "Best website builder for freelancers"

Each post = another doorway into your site.

---

## 3. Keyword targeting — get specific

Don't target the vague, ultra-competitive "web developer." Target niche, winnable keywords:

- "hire web developer Kenya"
- "website designer Nairobi"
- "e-commerce website development Kenya"
- "landing page design for coaches/therapists" (matches your featured service)

---

## 4. On-page improvements (can do today, no new pages)

1. **H1 optimization** — current hero H1 ("We build websites, e-stores & landing pages that convert.") has no strong keywords or location. Consider: "Web Designer & Developer in Kenya — Websites, E-Stores & Landing Pages."
2. **Schema markup (JSON-LD)** — add structured data:
   - `LocalBusiness` or `ProfessionalService` with Nairobi location
   - `Service` schema for each offering
   - Enables rich results (star ratings, etc.)
3. **NAP + map** — add Name, Address, Phone and embed a Google Map. Critical for local "Kenya/Nairobi" searches.
4. **Real portfolio w/ case studies** — screenshots, results, testimonials. Builds E-E-A-T (Experience, Expertise, Authoritativeness, Trustworthiness).
5. **Page speed** — you currently ship very large images (campaign-... 2.4MB, juanjo-... 4.5MB). Compress and convert to WebP/AVIF. Speed is a ranking factor.
6. **Internal links** — link between services and blog posts.

---

## 5. Off-page (critical but slower)

- **Google Business Profile** — list the business (Nairobi)
- **Local directory listings** — Kenya business directories
- **Backlinks** — guest posts, awards, open-source contributions, testimonials for tools you use, local partnerships

---

## 6. Honest expectations

- Ranking for "web developer" nationally/globally is **extremely competitive** — expect 6–12+ months of consistent content before real movement.
- Niche local keywords ("web developer Nairobi") are far more winnable in the short term.
- **Paid ads (Google Ads)** are the fastest route to immediate leads while SEO compounds slowly.

---

## Suggested priority order

1. Compress hero images (quick win, ranking factor)
2. Add JSON-LD LocalBusiness/Service schema
3. Fix hero H1 with keywords + location
4. Start blog + service pages
5. Set up Google Business Profile
6. Build backlinks (ongoing)
